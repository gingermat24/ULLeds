RELEASE NOTES

What changed

ULLeds 1.0.29

Current
Improved
  • Refreshed the interface with a more spacious Liquid Glass layout and refined controls.
  • Manual Screen Sync now uses the direct primary-display capture path already used by automatic resume.

ULLeds 1.0.28

Fixed
  • Preference switch thumbs stay vertically centered in both states.
  • Rapid setting changes are saved in order without allowing older responses to overwrite newer control values.
Improved
  • Power changes are sent immediately, and slider changes are flushed when released while continuing to update during dragging.

ULLeds 1.0.27

Fixed
  • Glass controls use a dark neutral tint instead of a white overlay.
  • Range slider thumbs are vertically centered on their tracks.

ULLeds 1.0.26

Changed
  • Removed the ULLeds logo and title from the top-left of the interface.
  • Reworked Liquid Glass with clearer frosted translucency and a cleaner, quieter surface treatment.
Removed
  • Removed decorative glow, ambient lighting, and drop shadows throughout the interface.

ULLeds 1.0.25

Changed
  • Redesigned the interface with optional Liquid Glass controls, adjustable transparency, animated tab selection, and filled range sliders.
Improved
  • Added clearer tab and control accessibility labels and keyboard selection state.
  • Screen Sync FPS remains editable while typing, and section changes return to the top.

ULLeds 1.0.24

Fixed
  • Controller discovery accepts valid device-info replies even when another HID reader changes the response ID.
  • Saved Screen Sync no longer suppresses manual lighting controls when automatic resume fails.

ULLeds 1.0.23

Fixed
  • Reset keeps the active controller connected and restores its detected profile.
  • The Windows app, tray, and refreshed shortcuts use the updated icon.
New
  • Choose between connected compatible controllers from Device settings.
Improved
  • Added separate release entries for every version from 1.0.0 through 1.0.23.

ULLeds 1.0.22

Improved
  • The top navigation stays centered when controller status changes.
  • Connection details fit their reserved space instead of shifting the tabs.
Changed
  • Updated the app artwork and regenerated the Windows icon.

ULLeds 1.0.21

Fixed
  • Reset clears saved settings without removing active browser data.
  • Windows shortcuts refresh to the current app icon after install or update.

ULLeds 1.0.20

New
  • Added a confirmation flow to reset saved settings and imported DX Light/QuikLight profiles.
Fixed
  • Reset preserves Electron browser data and only removes ULLeds settings and selected legacy profiles.

ULLeds 1.0.19

Changed
  • Fresh installs now start at #008100 and 50% brightness.
Improved
  • The interface fills wide windows and scales spacing and type up on large displays.
  • The Windows icon is generated from the supplied app.png.

ULLeds 1.0.18

New
  • Adjustable Screen Sync speed from 5 to 60 FPS, defaulting to 30.
  • A dedicated Updates page with local-folder updates and GitHub Releases marked Coming Soon.
Changed
  • Uses the matching saved LED count when the controller misses its count reply.
  • Screen capture and LED updates follow the selected FPS.
Improved
  • Device and update layouts adapt to narrower windows.
  • The app icon can be supplied as a PNG for the window, tray, and installer.
Fixed
  • Matching controllers can connect using their saved strip profile if the startup count handshake times out.
  • Reduced-motion preferences apply at every window size.

ULLeds 1.0.17

Improved
  • Screen Sync samples screen edges more responsively and calibrates RGB channels.

ULLeds 1.0.16

Fixed
  • Restored Screen Sync state cleanly when reopening the app.
