## ULLeds 1.0.99

### Fixed

* Spotify Sync no longer reacts to audio while Spotify is paused, stopped, or
  closed. Windows desktop capture returns the whole system mix, so the app now
  ignores that mix unless Windows reports Spotify as playing, and the strip rests
  on the current cover-art colors instead of pulsing to videos, calls, or
  notifications. While a track plays the analyzer still uses the system mix,
  because Windows does not offer per-app capture through this path.
* Fixed the Device page claiming **No compatible controller found** before the
  first controller scan, even though a controller was connected and working. The
  selector now lists the connected controller immediately, with its serial
  number, and the empty state only appears when nothing is connected.

### Documentation

* Added real screenshots of the Lighting tab, the Device tab, and the phone
  remote, with the local Wi-Fi address and pairing details hidden or blurred.
* Documented compatible hardware explicitly: USB IDs 0x1a86/0xfe07, a 253-LED
  maximum, one active controller at a time, and the fact that Screen Sync
  samples only the display Windows marks as primary.
* Described Spotify Sync accurately in the README, the security policy, and the
  Spotify panel itself: the analyzer listens to the system mix, and only while
  Spotify is playing.
* Documented the phone remote in the feature list, and added a **Get help**
  section that points at the issue templates, the security policy, and the
  contribution guide.
* Rewrote FUTURE-IMPROVEMENTS.md as a grouped roadmap, and corrected the
  widescreen entry to describe what 1.0.98 already fixed instead of repeating it
  as unscheduled work.

### Contributing

* Added CONTRIBUTING.md. Pull requests are welcome and are merged at the
  maintainer's discretion, with a license grant for accepted work; publishing a
  modified build or derivative app is still not allowed.
* Added SECURITY.md, a pull request template, and bug report and feature request
  issue templates.
* Narrowed the LICENSE notice: forking and building locally is permitted solely
  to prepare a pull request, while redistributing modified builds remains
  prohibited.
