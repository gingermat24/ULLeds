## ULLeds 1.0.98

### Improved

* Added priority-based lighting arbitration so Screen Sync and Spotify Sync can run concurrently; stopping one source reveals the next active source.
* Made effects regular priority-20 inputs and added a compact indicator for the currently winning input.
* Isolated USB controller protocol handling behind a device adapter and improved effect-to-solid transitions.
* Improved widescreen detection for near-black bars, separated stable detection from prompt policy, and kept an accepted picture area until the sync session restarts or the picture-area setting changes.
* Added temporary color and effect overrides from the desktop app and paired phone, with 5-second to 1-minute durations, manual clearing, automatic expiry, and restoration of the next active source.
* Preserved existing settings, saved scenes, phone remote behavior, and startup-mode restoration.

### Fixed

* Prevented controller scans from invoking the removed development-only override renderer.
* Accepted valid controller LED-count replies when another HID reader changes the response message ID, and clarified the saved-profile fallback warning.
* Released stale lighting inputs on disconnect so a stopped sync or expired override can no longer keep the strip unresponsive after reconnecting.
* Ignored an outdated winning frame whose color count no longer matches the connected strip, such as right after an LED-count change.
* Ensured an active temporary override no longer blocks the display from turning off when Windows signs out or shuts down.
* Closed the audio context when Spotify Sync startup is cancelled before playback begins.
