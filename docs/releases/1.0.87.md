## ULLeds 1.0.87

### Added

- Add a support form under Device settings where users can describe a problem and preview the GitHub issue before opening it.
- Keep diagnostic logs optional and unchecked by default. When selected, save the bounded logs as a local JSON attachment for the user to review and attach manually.

### Fixed

- Keep diagnostics out of the prefilled GitHub URL to avoid GitHub's request-length limit.
- Open only a prefilled draft. The problem description and basic app details go to GitHub when the draft opens; the issue is public only if the user submits it.
