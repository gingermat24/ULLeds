## ULLeds 1.0.93

### Improved

- Show the recovered Nov 9, 2026 release date for the archived 1.0.67 changelog entry.
- Stack Startup, Support, and Reset in a compact group that matches the size of the other settings panels.
- Add an optional phone remote for lighting and sync controls over a selected private Wi-Fi or Ethernet network, with QR-code and PIN pairing. Pair only on a trusted network; local traffic is not encrypted.
- Keep phone and desktop controls synchronized in both directions, and let users enter brightness as a percentage on either device while keeping its slider in sync.
