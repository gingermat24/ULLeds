## ULLeds 1.0.95

### Fixed

- The desktop color control now shows the most common color among selected LEDs.
- Changing color from the phone applies it across the strip and clears per-LED overrides.
- **Keep my data** now cancels a reset before data is removed, and a fresh reset can start after cancellation.
- Reset no longer waits for open phone-control requests or a follow-up controller scan when disconnected.
