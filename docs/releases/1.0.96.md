## ULLeds 1.0.96

### Improved

- Redesigned saved setup cards on desktop and phone with clearer color previews, readable details, and room for actions.
- In-app release notes now render Markdown bold text as bold instead of showing the `**` markers.
- Moved the Spotify auto-start option into Device > Sync to keep the Lighting controls focused.

### Added

- Spotify Sync now starts automatically when Spotify begins playing (on by default). It starts only while the LEDs are on and takes priority over Screen Sync; change this in Device > Sync.
- The first automatic start is announced in the app. Playback detection uses a lightweight local Windows media-session status check; no audio or track details are sent online.
