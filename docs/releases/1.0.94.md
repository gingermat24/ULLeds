## ULLeds 1.0.94

### Improved

- Use the full available window width with matching left and right content gutters, keeping layouts responsive.
- Give all tabs a consistent top-aligned title row, including Lighting.
- Match the content's bottom inset to the topbar's vertical spacing.
- Fit and enlarge the LED layout preview to the available desktop height while keeping the Light controls panel compact.
- Match the Startup, Support, and Reset panel padding to the other Device panels.
- Keep the phone remote's Sync settings divider clear of the Stop Sync button.
- Keep the phone remote URL stable across launches and retain paired access for a year across ULLeds restarts, unless unpaired or reset.
- Make the iPhone Home Screen remote reconnect automatically and explain temporary connection loss without showing a pairing prompt.

### Fixed

- Fix controller scanning and LED-selection controls failing when the renderer formats singular and plural labels.
- Keep Spotify Sync responsive when ULLeds is minimized by sampling audio on a fixed timer instead of display animation frames.
